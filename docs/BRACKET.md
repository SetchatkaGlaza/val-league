# Сетка, матчи и результаты (этап 5)

Статус: **5.1 (сервер) и 5.2 (страницы и админ-интерфейс) готовы**; 5.3 (массовое расписание, техпоражение, карты BO3) впереди. Сетку теперь можно вести целиком из админки, API нужен только для автоматизации.

## Жизненный цикл
1. Регистрация закрылась (или админ решил начать раньше). В админке турнира видно число оплаченных команд.
2. Админ **формирует сетку** `POST /api/admin/tournaments/:id/bracket` из оплаченных заявок (нужно минимум 2). Способы посева:
   - `random` — жеребьёвка (по умолчанию, криптографический генератор);
   - `registration` — по порядку оплаты: первые оплатившие становятся сеяными и получают проход без игры;
   - `manual` — порядок задаёт админ списком id заявок (`order`).
   Сетку можно пересоздавать, пока турнир не начался.
3. **Любое изменение состава оплаченных команд** (подтверждена новая, снята, отказалась) пока турнир в статусе «анонс» **удаляет готовую сетку**: её нужно сформировать заново, иначе в ней были бы лишние или отсутствующие команды.
4. «Начать турнир» работает только при готовой сетке (`409 bracket_required`). Неоплаченные заявки и лист ожидания снимаются.
5. Админ вводит результаты матчей. Победитель автоматически проходит дальше; результат финала **завершает турнир** и записывает победителя (команда + ники состава заявки) для главной страницы.

## Правила сетки (Single Elimination)
- Размер сетки — ближайшая степень двойки ≥ числа команд (2–128). Свободные места получают сеяные первыми: они проходят во второй раунд **без игры** (`bye`).
- Посев стандартный: 1–N, 4–5, 2–7, 3–6… Сильнейшие сиды встречаются как можно позже, №1 и №2 — только в финале.
- Названия раундов: «Финал», «Полуфинал», «Четвертьфинал», «1/8 финала» и т. д.
- Счёт: BO1 — по раундам (например 13:7, до 99), BO3 — по картам (2:0 или 2:1). Ничьей нет (`tie`), неверный счёт — `bad_score`.
- **Исправление результата** разрешено, пока следующий матч не начался. Если победитель меняется, он автоматически заменяется в следующем матче (`409 next_match_played`, если тот уже идёт или сыгран). Исправление счёта без смены победителя разрешено всегда. Результат финала можно исправить и после окончания турнира: победитель обновится.
- В идущем турнире оплаченную команду нельзя снять заявкой (`409 tournament_live`): такие случаи решаются результатом матча (в 5.3 появится техническое поражение).
- Закрыть турнир вручную можно, только если сетки нет или финал сыгран (`409 matches_unfinished`).

## Таблица `matches`
`tournament_id, round, position, reg_a, reg_b, name_a, name_b, seed_a, seed_b, score_a, score_b, winner ('a'|'b'), bye, status (pending|ready|live|finished), starts_at, lobby, demo_url, next_match_id, next_slot`.
Участники — оплаченные заявки; названия сохранены снимком. Связь «победитель идёт в матч» — `next_match_id` + `next_slot`. Данные лобби (`lobby`) видят только участники матча и админы, и только пока матч не сыгран.

## API
Публичные:
| Метод | Путь | Ответ |
| --- | --- | --- |
| GET | `/api/tournaments/:slug/bracket` | `{ tournament, preliminary, totalRounds, rounds: [{ round, name, matches }] }`; `preliminary: true`, пока турнир не начался |
| GET | `/api/matches/:id` | `{ match (+ rosterA/B, roundName), tournament, previous, viewer: { side } }`; `lobby` — только участникам и админам |
| GET | `/api/matches/mine` | матчи команд игрока (нужен вход) |

Админ (`/api/admin`):
| Метод | Путь | Тело |
| --- | --- | --- |
| GET | `/tournaments/:id/bracket` | сетка с данными лобби, `paidTeams`, `canGenerate` |
| POST | `/tournaments/:id/bracket` | `{ seeding: 'random'|'registration'|'manual', order? }` |
| DELETE | `/tournaments/:id/bracket` | убрать сетку (только пока турнир не начался) |
| PUT | `/matches/:id/result` | `{ scoreA, scoreB }` |
| PATCH | `/matches/:id` | `{ startsAt?, lobby?, demoUrl?, status?: 'ready'|'live' }` |

Коды ошибок: `not_enough_teams, bad_state, bracket_required, matches_unfinished, bye_match, not_ready, bad_score, tie, next_match_played, tournament_live`.

## Проверка
- Юнит-тесты логики сетки (посев, bye, связи, названия раундов, счёт): `npm test` (11 тестов, БД не нужна).
- Сквозная проверка (`npm run smoke`): формирование и пересоздание сетки, сброс при изменении состава, старт, лобби участникам и скрытие от посторонних, ввод и исправление результата, автозавершение турнира.

## Страницы и интерфейс (5.2)
| Адрес | Что там |
| --- | --- |
| `/tournaments/<slug>/bracket` | Сетка по раундам: линии между матчами, победитель подсвечен, идущий матч с отметкой «Идёт». На телефоне сетка листается вправо, над ней кнопки быстрого перехода к раунду. Идущий и предварительный турнир обновляются сами раз в 30 с. Победитель финала показан в шапке |
| `/matches/<id>` | Счёт, команды, составы, «Путь к этому матчу», ссылка на следующий матч и демо. Участникам матча и админам, пока матч не сыгран, показываются данные лобби с кнопкой «Скопировать». Страница обновляется сама раз в 20 с |
| `/admin/tournaments/<id>` → «Сетка и матчи» | Посев (жеребьёвка / по порядку оплаты / вручную со списком «Выше / Ниже»), формирование и удаление сетки, ввод и исправление счёта, «Матч начался», время, лобби и ссылка на демо. Счёт проверяется до отправки теми же правилами, что на сервере |
| `/account` → «Мои матчи» | Ближайшие, идущие и сыгранные матчи команд игрока: соперник, раунд, время, итог «Победа 13:7» / «Поражение». Подключение — на странице матча |
| `/tournaments/<slug>` | Кнопка «Турнирная сетка» (для анонса — «Предварительная сетка»), пока сетка есть или турнир идёт/завершён |

Что меняется само: после подтверждения/снятия оплаты в админке раздел сетки перечитывается (сервер мог её сбросить); результат финала обновляет панель статуса и победителя.

Серверная правка 5.2: в ответ по турниру добавлено `hasBracket` (есть ли сетка), чтобы показывать кнопку только когда она нужна.

## 5.3a: расписание, техпоражение, неявка
- **Массовое расписание** (админка → «Сетка и матчи» → «Назначить время матчей»): время первого матча, интервал в минутах, сколько матчей идёт одновременно. Следующий раунд начинается через интервал после последнего матча предыдущего. Сыгранные, идущие матчи и проходы без игры не меняются; уже назначенное время сохраняется, пока не отмечено «Заменить уже назначенное время».
- **Результат без игры:** в форме результата выберите «Техническое поражение» или «Неявка» и проигравшую команду. Победителю записывается счёт 13:0 (BO1) или 2:0 (BO3), на сетке и странице матча стоит подпись причины. Результат можно исправить на обычный счёт.
- **Демо:** ссылку можно указать прямо при вводе результата.

## 5.3b: счёт по картам BO3
- В форме результата BO3 выберите «Сыгран, счёт по картам»: для каждой карты — название (из пула карт турнира), очки раундов и необязательная ссылка на демо. Третья карта появляется, только если первые две разделились 1:1. Счёт серии (2:0 или 2:1) считается автоматически.
- «Только итог серии» — если очков по картам нет: вводится 2:0 или 2:1.
- Страница матча показывает карточку «Карты» (карта, очки, демо карты), а сетка и «Мои матчи» — итоговый счёт серии.
