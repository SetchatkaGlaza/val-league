# VAL Telegram Bot — starter pack

Проект для интеграции Telegram с VOLOGDA AMATEUR LEAGUE (VAL).
Сайт: https://github.com/SetchatkaGlaza/val-league

**Важно:** это стартовый сервис и документация, а не заявление, что интеграция уже подключена к сайту. Контракты API ниже требуют реализации/сверки с текущим backend.

## Состав
- `bot/` — Node.js 20+, Telegraf + Express.
- `docs/` — контекст проекта, ТЗ, API-контракты, безопасность, тест-план.
- `prompts/` — пошаговые промпты для ИИ-разработчика.
- `assets/` — SVG-заготовки бренда VAL.

## Запуск
1. Установи Node.js 20+.
2. Создай бота через Telegram `@BotFather`.
3. Скопируй `bot/.env.example` в `bot/.env`, заполни токен и секреты.
4. В терминале: `cd bot`, `npm install`, `npm run dev`.

Не публикуй `.env` и токен бота. Бот отвечает на `/start`, `/help`, `/privacy`, имеет health endpoint и защищённый внутренний endpoint уведомлений. Привязка заработает только после реализации endpoint в основном backend сайта.

## Архитектура
Сайт VAL остаётся источником истины для пользователей, команд и турниров. Telegram-бот — отдельный сервис для команд и уведомлений. Предлагаемые endpoints в `docs/INTEGRATION_CONTRACTS.md` не считаются существующими, пока их не реализовали и не протестировали.

На момент сборки архива не запускались реальные Telegram API, PostgreSQL и smoke-тесты сайта. Сверь фактический код, затем пройди `docs/TEST_PLAN.md`.
