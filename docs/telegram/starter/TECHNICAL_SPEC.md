# ТЗ: Telegram-бот VAL

## Основные функции
- `/start`: приветствие, кнопка сайта, обработка `link_<token>` deep link.
- `/help`, `/privacy`: помощь и ссылка на политику.
- Привязка Telegram к авторизованному аккаунту VAL одноразовым короткоживущим токеном.
- Уведомления: приглашение в команду, статус заявки на турнир, подтверждение ручной оплаты, расписание матча, напоминание, опубликованный результат — после реализации соответствующих доменных событий.
- Внутренний endpoint доставки уведомлений от backend к боту.
- Настройки уведомлений и отвязка — отдельная реализация в основном backend.

## Архитектура
- `bot/src/index.js`: Telegraf, Express, health, internal notify.
- `bot/src/handlers`: команды.
- `bot/src/services`: клиент VAL API и доставка.
- Backend сайта владеет пользователями и связями Telegram, выдаёт токены и публикует события.
- Production: transactional outbox в основной БД, worker, retries/backoff, persistent idempotency, dead-letter обработка.

## Безопасность
- Токены только в env/secret manager.
- Link token создаётся только авторизованным backend, хранится как хеш, короткий TTL, одноразовое использование и атомарное потребление.
- Не доверять Telegram username или переданному клиентом VAL user ID.
- Internal endpoint защищён секретом, HTTPS, rate limit, schema validation, allowlist событий.
- URL-кнопки разрешать только на домене сайта.
- Не слать секреты, пароли, платёжные данные или сессионные cookies.
- Ошибка Telegram не должна откатывать бизнес-операцию сайта.
- Админ-команды требуют серверной авторизации.

## Критерии готовности
Команды работают; привязка защищена от истёкших/повторных токенов; уведомление приходит правильному пользователю; неавторизованный internal запрос отклоняется; повторные события не дублируются после реализации постоянной идемпотентности; тесты и release checklist пройдены.
