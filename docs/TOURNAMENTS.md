# Турниры и админка

## Жизненный цикл
`draft` (черновик, виден только админам) → `upcoming` (анонс/регистрация) → `live` (идёт) → `finished` (прошёл).
Начать турнир можно, только когда сформирована сетка (`docs/BRACKET.md`); финал автоматически завершает турнир.
Отмена (`cancelled`) возможна из `upcoming` и `live`; отменённый можно восстановить в `upcoming` или вернуть в `draft`.
Из `upcoming` можно вернуться в `draft`. Завершённый турнир изменить нельзя.

Правила редактирования:
- в `draft` и `upcoming` меняется всё (название, дата, формат состава 5x5/2x2, BO1/BO3, лимит команд, взнос, призовые, пул карт);
- в `live`, `finished`, `cancelled` — только описание и «регистрация открыта» (сервер вернёт `409 locked`);
- дата начала при создании и публикации должна быть в будущем; у уже анонсированного турнира, чьё время прошло, описание править можно;
- удалять можно только `draft` и `cancelled`.

Призовые — список мест подряд (1, 2, 3…), сумма считается сама (`prizeTotal`). Пул карт — из списка CS2 (`server/src/config.js` → `maps`;
тот же список в `client/src/views/admin-tournament.js`). Адрес `/tournaments/<slug>` собирается из названия один раз и не меняется.
Победитель при завершении указывается вручную (команда и до 7 ников); на этапе сетки он будет подставляться из результатов.

## Страницы
| Адрес | Кто | Что |
| --- | --- | --- |
| `/tournaments` | все | вкладки «Предстоящие / Идут сейчас / Прошедшие» со счётчиками, карточки; если предстоящих нет, а турнир идёт — открывается «Идут сейчас» |
| `/tournaments/<slug>` | все | дата, таймер, формат, взнос, призовые, пул карт, описание, список команд, победитель; для статуса сообщает, можно ли регистрироваться |
| `/teams` | все | каталог команд с поиском |
| `/admin` | админ | сводка (игроки, команды, активные турниры) и таблица всех турниров |
| `/admin/tournaments/new`, `/admin/tournaments/<id>` | админ | форма, панель статуса, победитель, удаление; защита от потери правок |

Главная берёт «Ближайший турнир» (идущий или ближайший по дате) и «Последних победителей» из БД; если данных нет — показывает понятные заглушки.

## API
Публичные:
| Метод | Путь | Ответ |
| --- | --- | --- |
| GET | `/api/tournaments?tab=upcoming\|live\|past` | `{ tab, tournaments, counts }` (до 60, без черновиков) |
| GET | `/api/tournaments/next` | `{ tournament \| null }` |
| GET | `/api/tournaments/:slug` | `{ tournament, teams }`; `404` для черновиков |
| GET | `/api/winners?limit=3` | `{ winners: [{ slug, tournament, date, team, roster, prize }] }` |
| GET | `/api/teams?q=&offset=` | `{ teams, total, limit }` (24 на страницу) |

Админские (`/api/admin`, роль `admin`, иначе `403`):
| Метод | Путь | Тело |
| --- | --- | --- |
| GET | `/dashboard` | — |
| GET / POST | `/tournaments` | создание: `name, startsAt, maxTeams` + необязательные `description, teamSize, matchFormat, fee, mapPool, prizePlaces, registrationOpen` |
| GET / PATCH | `/tournaments/:id` | любые поля из создания |
| POST | `/tournaments/:id/status` | `{ status, winnerName?, winnerRoster? }`; `409 bad_transition / start_in_past` |
| DELETE | `/tournaments/:id` | `409 not_deletable` |

Коды ошибок валидации: `400 { code: 'validation', field }`.

## Как назначить администратора
`npm run admin:make -- почта_или_ник` (снять права: добавьте `--remove`). Последнего администратора нельзя удалить из «Настроек».

## Заявки команд (этап 4)
Подробно — `docs/REGISTRATION.md`. В админке турнира блок «Заявки команд»: подтвердить оплату, снять заявку, отметить возврат.
Счётчики в API турнира: `teamsCount` (занятые места), `paidCount`, `waitlistCount`, `canRegister`, `registrationClosesAt`.

## Что было подготовлено под этап 4 (теперь сделано)
`teamsCount` пока всегда 0, `teams` в ответе страницы турнира — пустой список: когда появятся заявки, меняется одна функция
(`teamsCount` в `server/src/controllers/tournaments.js`) и запрос списка команд. Кнопка регистрации на странице турнира сейчас объясняет, что регистрация откроется позже.
