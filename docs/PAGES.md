# Страницы (статус)
Все страницы — части одного SPA (`client/src/views`), адреса без `.html`.

- [x] login — вход (`/login`), работает с сервером и БД (см. `docs/AUTH.md`)
- [x] register — регистрация (`/register`)
- [x] forgot — восстановление пароля (`/forgot`)
- [x] verify-email — «Проверьте почту», повторная отправка, «Почта подтверждена», устаревшая ссылка (`/verify-email`)
- [x] reset-password — «Придумайте новый пароль», успех, устаревшая ссылка (`/reset-password`)
- [x] rules — регламент (`/rules`, также шторкой из форм)
- [x] privacy — политика конфиденциальности (`/privacy`, также шторкой из форм)
- [x] 404 — страница ошибки (`/что-угодно`)
- [x] home — главная (`/`): герой, ближайший турнир с таймером и призовым, о лиге, победители, партнёры. Данные пока демо: `client/src/data/demo.js`
- [x] account — личный кабинет (`/account`, только для вошедших): профиль, привязка Steam и Telegram, мои команды и приглашения; турниры и матчи (пока пустые состояния)
- [x] settings — настройки аккаунта (`/settings`, только для вошедших): профиль, смена пароля, уведомления, удаление аккаунта
- [x] teams/new — создание команды (`/teams/new`, только для вошедших): название, описание, логотип
- [x] team — страница команды (`/teams/<slug>`, публичная): состав, капитан, приглашения, настройки, история турниров (пока пустая). Подробности: `docs/TEAMS.md`
- [x] invite — «Вас пригласили в команду» (`/invite?token=…` или `?id=…`): принять / отклонить
- [ ] tournaments, tournament, bracket
- [ ] winners, rating, news, about, advertisers
- [ ] admin/*

Реквизиты организатора для регламента и политики — `client/src/config.js`.
