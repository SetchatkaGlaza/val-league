# Страницы (статус)
Все страницы — части одного SPA (`client/src/views`), адреса без `.html`.

- [x] login — вход (`/login`), работает с сервером и БД (см. `docs/AUTH.md`)
- [x] register — регистрация (`/register`)
- [x] forgot — восстановление пароля (`/forgot`)
- [x] verify-email — «Проверьте почту», повторная отправка, «Почта подтверждена», устаревшая ссылка (`/verify-email`)
- [x] reset-password — «Придумайте новый пароль», успех, устаревшая ссылка (`/reset-password`)
- [x] rules — регламент (`/rules`, также шторкой из форм)
- [x] privacy — политика конфиденциальности (`/privacy`, также шторкой из форм)
- [x] 404 — страница ошибки (`/что-угодно`)
- [x] home — главная (`/`): герой, ближайший турнир с таймером и призовым, о лиге, последние победители, партнёры. Данные из БД (`/api/tournaments/next`, `/api/winners`)
- [x] account — личный кабинет (`/account`, только для вошедших): профиль, привязка Steam и Telegram, мои команды и приглашения (ссылка в админку для администраторов); «Мои турниры» — заявки со статусами; матчи (пока пустое состояние)
- [x] settings — настройки аккаунта (`/settings`, только для вошедших): профиль, смена пароля, уведомления, удаление аккаунта
- [x] teams/new — создание команды (`/teams/new`, только для вошедших): название, описание, логотип
- [x] team — страница команды (`/teams/<slug>`, публичная): состав, капитан, приглашения, настройки, история турниров (пока пустая). Подробности: `docs/TEAMS.md`
- [x] invite — «Вас пригласили в команду» (`/invite?token=…` или `?id=…`): принять / отклонить
- [x] tournaments — список турниров (`/tournaments`): вкладки «Предстоящие / Идут сейчас / Прошедшие»
- [x] tournament — страница турнира (`/tournaments/<slug>`): таймер, формат, взнос, призовые, пул карт, описание, команды, победитель. Регистрация команды, оплата, лист ожидания (блок «Участие»)
- [x] teams — каталог команд с поиском (`/teams`)
- [x] bracket — сетка турнира (`/tournaments/<slug>/bracket`): раунды, линии, горизонтальная прокрутка на телефоне, автообновление. Подробности: `docs/BRACKET.md`
- [x] match — страница матча (`/matches/<id>`): счёт, составы, путь команд, данные лобби участникам
- [x] admin — сводка и список турниров (`/admin`), форма турнира со сменой статуса (`/admin/tournaments/new`, `/admin/tournaments/<id>`). Подробности: `docs/TOURNAMENTS.md`
- [ ] bracket, match
- [ ] winners, rating, news, about, advertisers
- [ ] остальная админка: заявки, оплаты, пользователи, новости, реклама

Реквизиты организатора для регламента и политики — `client/src/config.js`.
