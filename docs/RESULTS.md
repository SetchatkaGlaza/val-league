# Итоги турниров, архив победителей, публичные страницы (этап 6)

Статус: **6.1 и 6.2 готовы** (итоги, архив, история команды). 6.3 (профиль игрока) впереди.

## Что есть в 6.1
- **Призёры по сетке.** Для завершённого турнира сервер определяет 1 место (победитель финала), 2 место (проигравший финалист) и 3 место (два проигравших полуфиналиста: матча за 3 место в Single Elimination нет, поэтому оно общее). В турнире на двоих сетка из одного матча даёт только 1 и 2 места; у турнира из 3 команд призёр 3 места один.
  Турнир, закрытый вручную без сетки (старые турниры), показывает только победителя (`tournaments.winner_name`).
- **Страница турнира** — блок «Итоги турнира»: места, составы победителей, призы за 1 и 2 места, кнопка «Смотреть сетку». Приз 3 места в блоке не указан (его делят двое), полный список призов остаётся в карточке «Призовой фонд».
- **Архив победителей** — страница `/winners` (пункт «Победители» в шапке и подвале): карточки турниров от новых к старым, призёры, формат, число команд, призовой фонд, кнопки «Итоги турнира» и «Сетка»; подгрузка по 8 («Показать ещё»).
- **Вкладка «Прошедшие»** на `/tournaments` — в карточках победитель и 2–3 места.
- **Главная** — в «Последних победителях» добавлено 2–3 место и ссылка на архив.

## API
| Метод | Путь | Что изменилось |
| --- | --- | --- |
| GET | `/api/tournaments/:slug` | в `tournament` добавлено `podium` (`null`, пока турнир не завершён) |
| GET | `/api/tournaments?tab=past` | у завершённых турниров есть `podium` |
| GET | `/api/winners?limit=&offset=` | добавлены `total`, `podium`, `hasBracket`, `teamSize`, `matchFormat`, `teamsCount`, `prizeTotal`; `limit` до 50 |

`podium`: `{ first, second, thirds: [] }`, где команда — `{ name, slug, logo, roster: [ники] }` (`slug` пустой, если команду удалили).

## Как устроено
- Чистая логика: `server/src/services/results.js` (`computeResults`, `resultFor`) — по матчам сетки находит победителя, финалиста, полуфиналистов и стадию вылета каждой команды. Её же использует 6.2 для истории команд.
- Загрузка данных: `loadPodiums` в `server/src/controllers/tournaments.js` (два запроса на любое число турниров).
- Клиент: `views/podium-parts.js`, `views/winners.js`, `styles/results.css`.

## Найдено и исправлено попутно
Атрибут `hidden` не скрывал кнопки: у `.btn` задан `display`, поэтому «Показать ещё» оставалась видна после загрузки всего списка (в том числе на `/teams`). В `base.css` добавлено правило `[hidden] { display: none !important; }`.

## История команды (6.2)
Блок «История и результаты» на странице команды `/teams/<slug>`: по каждому турниру, в котором команда подтверждена (оплачена), — место (1–3) или стадия вылета, победы и поражения в сетке, состав (у завершённых турниров), ссылки на турнир и сетку. Сверху — число турниров, титулы, призовые места, счёт матчей.

| Метод | Путь | Ответ |
| --- | --- | --- |
| GET | `/api/teams/:slug/history` | `{ team: { name, slug }, stats: { tournaments, titles, podiums, matchWins, matchLosses }, history: [{ tournament: { slug, name, startsAt, status, teamSize, matchFormat }, place, stage, inGame, hasBracket, record, roster }] }` |

Подписи на клиенте: `place` → «1/2/3 место»; иначе «В игре», «Вылет: <стадия>», «Заявка подтверждена» (будущий турнир), «Идёт турнир», «Участие» (завершён, места нет). Чистая логика и тесты: `services/team-history.js`, `test/team-history.test.js`.

Ограничения: команда, которую удалили, страницы не имеет (её история остаётся только в архиве турниров); заявки, снятые или не оплаченные, в историю не попадают.

## Профиль игрока (6.3)
Страница `/players/<ник>`: итоги (турниры, титулы, призовые места, счёт матчей команд) и список завершённых турниров с командой, местом или стадией вылета, ссылками на турнир и сетку.

| Метод | Путь | Ответ |
| --- | --- | --- |
| GET | `/api/players/:nick` | `{ player: { nick }, stats: { tournaments, titles, podiums, bestPlace, matchWins, matchLosses }, history: [{ tournament, place, stage, hasBracket, record, team: { name, slug }, roster }] }`; 404, если ника нет среди аккаунтов |

Ограничения: турниры ищутся по нику в составе заявки (после смены ника старые не находятся); идущие и будущие турниры не показываются.
