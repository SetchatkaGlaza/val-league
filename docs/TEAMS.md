# Команды

## Правила
- Создать команду может любой вошедший игрок: название 3–24 символа (буквы, цифры, пробел, `_ . -`), описание до 300, логотип по желанию.
- Создатель — капитан и первый игрок основы. Основа до **5** человек, запасных до **2** (лимиты — `server/src/config.js`, `teams`).
- Один игрок может быть капитаном не более чем **3** команд и состоять не более чем в **10**.
- Вступившего ставят в основу, если там есть место, иначе в запас. Капитан переводит игроков между основой и запасом.
- Капитан не может уйти: сначала передаёт капитанство (в меню «Действия» у игрока) или удаляет команду.
- Адрес команды `/teams/<slug>` собирается из названия (транслитом) один раз и не меняется при переименовании.

## Приглашения
- **По нику**: капитан вводит ник, игрок видит приглашение в личном кабинете (или по ссылке `/invite?id=…`) и принимает или отклоняет. До 20 неотвеченных приглашений на команду.
- **По ссылке**: у команды одна многоразовая ссылка `/invite?token=…`, её видит только капитан. Пока в составе есть место, ею может воспользоваться любой вошедший. «Сбросить ссылку» делает старую недействительной.
- Без входа ссылка ведёт на `/login?next=…`, после входа человек возвращается на приглашение.
- Уведомления о приглашении на почту и в Telegram появятся вместе с этапом уведомлений.

## Логотип
Клиент обрезает картинку до квадрата 256×256 и отправляет webp (или png). Сервер принимает `PUT /api/teams/:slug/logo` с телом-картинкой до 1 МБ, тип определяет по первым байтам (PNG/JPEG/WebP; SVG не принимается), сохраняет под случайным именем в `UPLOADS_DIR/logos` и отдаёт по `/api/files/logos/<имя>`.

## API (`/api/teams`, `/api/invites`)
| Метод | Путь | Кто | Тело → ответ |
| --- | --- | --- | --- |
| GET | `/teams/mine` | вошедший | `{ teams, invites }` |
| POST | `/teams` | вошедший | `{ name, description }` → `201 { slug }`; `409 name_taken / too_many_owned / too_many_teams` |
| GET | `/teams/:slug` | все | `{ team, members, viewer, tournaments }`; капитан дополнительно `inviteToken`, `invites` |
| PATCH | `/teams/:slug` | капитан | `{ name?, description? }` |
| DELETE | `/teams/:slug` | капитан | — |
| PUT / DELETE | `/teams/:slug/logo` | капитан | картинка / — |
| POST | `/teams/:slug/invites` | капитан | `{ nick }`; `404 user_not_found`, `409 already_member / already_invited / team_full` |
| DELETE | `/teams/:slug/invites/:id` | капитан | отозвать приглашение |
| POST | `/teams/:slug/invite-link/reset` | капитан | → `{ inviteToken }` |
| PATCH | `/teams/:slug/members/:userId` | капитан | `{ role: 'main' \| 'sub' }`; `409 main_full / sub_full` |
| DELETE | `/teams/:slug/members/:userId` | капитан или сам игрок | исключить / выйти; `409 captain_cannot_leave` |
| POST | `/teams/:slug/captain` | капитан | `{ userId }` — передать капитанство |
| GET | `/invites/preview?token=` или `?id=` | вошедший | `{ state: ok / already_member / full, team, invitedBy, members, limit }`; `404 invite_invalid` |
| POST | `/invites/accept` | вошедший | `{ token }` или `{ id }` → `{ slug }` |
| POST | `/invites/decline` | вошедший | `{ id }` |

Изменения состава идут в транзакции с блокировкой строки команды, поэтому два одновременных вступления не превысят лимит.
